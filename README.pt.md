## <img src="https://github.com/KrishBharadwaj5678/Dinoverse/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como funciona

### 1️⃣ Baixe as imagens

- **Baixe as imagens** da pasta `markers` do repositório para o seu dispositivo.

### 2️⃣ Baixe o aplicativo

- [Baixe o aplicativo](https://drive.google.com/file/d/1C9f9p4G6hup2rYGygBp1nDcvZmMloFZt/view?usp=sharing) usando o link disponibilizado no repositório.

### 3️⃣ Inicie o aplicativo

- **Abra o aplicativo** para começar sua experiência imersiva de realidade aumentada.

### 4️⃣ Digitalize a imagem

- **Digitalize qualquer imagem baixada** usando o aplicativo para ativar a experiência de RA.

### 5️⃣ Explore a realidade aumentada

- **Visualize o dinossauro em 3D** e interaja com ele por meio da realidade aumentada.
