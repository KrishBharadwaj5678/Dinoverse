## <img src="https://github.com/KrishBharadwaj5678/Dinoverse/raw/main/readme/gifs/features.gif" width="35"/> Возможности

| Возможность | Краткое описание |
| --- | --- |
| ✨ **Визуализация динозавров в 3D** | Исследуйте детализированные 3D-модели динозавров |
| 🥽 **Дополненная реальность (AR)** | Размещайте динозавров в окружающем вас реальном мире |

| ⚡ **Взаимодействие в реальном времени** | Оживляйте динозавров с помощью интерактивных функций |

## <img src="https://github.com/KrishBharadwaj5678/Dinoverse/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

### 1️⃣ Скачайте изображения

- **Скачайте изображения** из папки `markers` в репозитории на своё устройство.

### 2️⃣ Скачайте приложение

- [Скачать приложение](https://drive.google.com/file/d/1C9f9p4G6hup2rYGygBp1nDcvZmMloFZt/view?usp=sharing) можно по ссылке, предоставленной в репозитории.

### 3️⃣ Запустите приложение

- **Откройте приложение**, чтобы начать погружение в мир дополненной реальности.

### 4️⃣ Отсканируйте изображение

- Сканируйте изображение, чтобы запустить AR-сцену.

### 5️⃣ Исследуйте дополненную реальность

- Изучайте 3D-динозавров в дополненной реальности.
