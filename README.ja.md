<h1 align="center">🦖 Dinoverse</h1>

<p align="center">
  Dinoverseの没入型リアルタイム3Dスキャン体験で、恐竜たちを現実世界によみがえらせましょう。
</p>

## <img src="https://github.com/KrishBharadwaj5678/Dinoverse/raw/main/readme/gifs/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
| --- | --- |
| ✨ **3D恐竜ビジュアライゼーション** | 精巧に作られた恐竜の3Dモデルを探索できます |
| 🥽 **AR体験（拡張現実）** | 現実の周囲の環境に恐竜を出現させることができます |
| 🎯 **画像認識・トラッキング** | 恐竜の画像をスキャンして3Dモデルを表示できます |
| ⚡ **リアルタイム操作** | インタラクティブな機能で恐竜を瞬時に動かせます |

## <img src="https://github.com/KrishBharadwaj5678/Dinoverse/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

### 1️⃣ 画像をダウンロードする

- リポジトリ内の `markers` フォルダから**画像をダウンロード**し、お使いのデバイスに保存してください。

### 2️⃣ アプリをダウンロードする

- リポジトリに記載されているリンクから[アプリをダウンロード](https://drive.google.com/file/d/1C9f9p4G6hup2rYGygBp1nDcvZmMloFZt/view?usp=sharing)してください。

### 3️⃣ アプリを起動する

- **アプリを開いて**、没入型の拡張現実体験を始めましょう。

### 4️⃣ 画像をスキャンする

- アプリを使ってダウンロードした画像を**スキャン**すると、AR体験が始まります。

### 5️⃣ AR体験を楽しむ

- **恐竜の3Dモデルを立体的に表示**し、拡張現実の世界で恐竜との体験を楽しみましょう。
